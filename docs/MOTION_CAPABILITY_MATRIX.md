# Motion能力矩阵

目标版本：`motion_capability_matrix_v1`。本文件是Motion后续配方、评分、选模和播放测试的共同目标入口。目标已确认；本次仅交付文档，没有更改运行实现或宣布模型通过。

## 领域边界与优先级

Motion负责稳定站立、前后运动、普通原地自转、行进转弯、变高后运动和地形适应。0.34m基础能力优先，学习新任务期间持续复习，不以新任务平均分抵消基础退化。

Recovery负责从合法Swing自主起身并连续保持10秒；Motion的抗扰恢复指运动支撑状态下受扰后恢复稳定，不授予倒地起身能力。Jump由其领域负责人定义。Spin另训高速双向纯自转，最终速度上限不由本矩阵规定；本文件不分配Spin额度、不启动Spin。Motion与Spin由用户在静止状态切换，本阶段不设计高速跨技能交接。

## 目标矩阵

优先级P0为持续保留的基础，P1为主要扩展，P2为后续组合扩展。每项必须分别记录标称、DR及外部扰动条件，不能用混合均值宣称全部通过。

| 能力ID | 能力与期望范围 | 解锁与保留关系 | 优先级 |
|---|---|---|---|
| M01 | 平地0.34m稳定站立；真实dq输入下低振荡、双轮支撑、无持续明显溜车 | 全程保留；不要求精确零位移停车 | P0 |
| M02 | 平地0.34m直线前进、后退，速度范围覆盖至±3.6m/s | 两方向分别记录；保住高速，同时覆盖中间速度，不追求精确低速跟踪 | P0 |
| M03 | 平地0.34m普通原地自转，正反方向覆盖至±2rad/s | 两方向分别记录；2rad/s是Motion目标范围，不是新加执行限速器 | P0 |
| M04 | M01～M03在观测延迟、执行延迟、DR和外部扰动下保持任务能力 | 基础标称与当前难度持续采样；逐级扩大困难范围 | P0 |
| M05 | 0.34m行进转弯，前进/后退与正/负yaw共四个方向组合 | 先易速度/yaw组合，再扩大；每方向独立进退级；真实完成转向才算通过 | P1 |
| M06 | 四种H1地形分别实现稳定直线运动 | 各地形先低速，再逐级提高；以3.6m/s为逐级探索目标，不宣称当前可达或全部已解锁 | P1 |
| M07 | 先改变高度并稳定，再在固定目标高度站立或运动 | 高度以0.34m为中心向两端扩展，最终覆盖0.20～0.40m；各高度先站立，再直线 | P1 |
| M08 | 不同高度下的转弯、地形运动与更强鲁棒性组合 | 该高度基础能力及相应转弯/地形单项先通过，再组合 | P2 |

M06地形为`steep_waves_H1`、`cobblestones_H1`、`broken_rubble_H1`、`pitted_road_H1`。名称不是几何身份，配方和成绩须绑定实际碰撞资产与高度查询来源。高度定义为`root_world_z - actual_ground_triangle_z(root_xy)`；平地使用其明确地面高度。

M07的最终目标是高度覆盖。除0.34m已明确的±3.6m/s核心目标外，其他高度的最高速度、最大yaw和地形组合范围待对应配方明确；不默认承诺所有高度、所有地形均满速，也不自动降低已声明目标。

## 姿态与对称性

| 场景 | 机体姿态 | 双腿对称性 |
|---|---|---|
| 平地站立、平地直线前后运动 | 基本水平，pitch/roll受控，允许必要瞬态 | 要求对称；变高后相同平地场景沿用此规则 |
| 普通原地自转 | 基本水平，姿态和支撑稳定 | 不强求 |
| 崎岖地形站立、直线运动 | 以机体基本水平及支撑稳定为目标，允许路面带来的必要波动，不强迫每个瞬间零姿态 | 不强求 |
| 行进转弯，包括未来地形转弯 | 允许合理主动内倾；roll随转弯变化，pitch保持稳定 | 允许左右腿长差及不对称 |
| 变高过程、受扰恢复瞬态 | 检查过渡稳定、超调、恢复时间及最终状态，不能靠刚性对称要求阻碍必要平衡动作 | 按场景处理，不对所有瞬态套同一硬约束 |

对称性依据模型通道与几何镜像合同判定，不交换网络数组，不以左右关节数值直接相等代替镜像关系。只有平地站立、平地直线的对称性是目标约束，不能扩展到转弯、自转或rough。

内倾是完成稳定转弯的手段，不是任务通过的替代指标。必须同时检查实际vx、实际yaw、支撑、姿态和失稳；“双轮支撑合格”“有内倾”均不能掩盖欠转。内倾软参考不能成为机械强制姿态，具体范围和评分由显式版本合同定义。

## 课程与解锁关系

| 阶段 | 主攻内容 | 前置条件与保留项 |
|---|---|---|
| 基础巩固 | 0.34m站立、直线±3.6m/s、原地±2rad/s及其鲁棒性 | 从实际来源能力出发，不把已有能力清零；持续保留标称与当前DR复习 |
| 转弯扩展 | 四方向从容易的速度/yaw组合逐级扩大 | 基础达到保留门槛；不能仅靠姿态分晋级 |
| 地形扩展 | 四种H1各自从低速推进 | 基础达到保留门槛；可与转弯扩展并行，各轴独立推进 |
| 高度扩展 | 向低、高两方向扩展站立，再在固定高度运动 | 对应高度站立稳定后增加运动；不把降高过程混入固定高度稳态成绩 |
| 能力组合 | 不同高度下转弯、地形及更困难DR | 对应单项具备能力；逐次扩大少数困难维度 |

阶段是配方设计次序，不是已实现的全局自动调度器。现有`SplitCourse`已支持任务轴独立晋退级；基础保留门槛对训练分配的约束、跨能力前置关系及新高度组合仍须在后续配方/实现中接线与验证，不能仅凭本文件宣称生效。

课程继续复用同条件连续确认、明确退化才回退、UNKNOWN中断确认但不制造失败的机制。确认绑定实际方向、命令、高度、DR和执行合同；无关方向变化不清空全部历史。共享DR强度轴独立于任务轴推进，不改成每个DR家族各自晋级。DR与外部扰动分别记录，观测年龄、目标运输、PD后运输、电机响应不能重复叠加。

保留已掌握能力的采样配额；转弯或地形晋级不移除0.34m基础复习。具体配额、速度/yaw/高度阶梯、连续确认次数、退级阈值和DR范围以新配方明确声明，本文件不隐式改写旧冻结配置。

## 每个模型的能力成绩单

目标矩阵可被多个模型共用，成绩单必须绑定一个确切checkpoint的路径/SHA、来源、模型与执行合同版本、目标矩阵版本。权重相同但执行合同不同，也不能沿用原成绩。

每个能力格绑定：能力ID、地形资产/几何身份、实际目标高度、vx、yaw、DR强度及采样范围、外部扰动、传感/执行时序、评分协议。后端及物理配置也纳入身份。名义与DR、不同高度/命令/地形难度的结果分格保存；不将所有维度盲目做全笛卡尔积，先覆盖P0和当前解锁前沿。

| 记录项 | 必须表达的内容 |
|---|---|
| 覆盖 | 结束/完整回合数、评分时长、种子、Student有效样本与全部transition；没有覆盖记UNKNOWN |
| 任务表现 | 实际vx/yaw及误差、高度误差、转弯响应；均值以外保留协议要求的分布/尾部指标 |
| 稳定质量 | 完整回合比例、失稳与越界、roll/pitch、双轮支撑、振荡、持续漂移、受扰恢复表现 |
| 场景约束 | 仅适用场景的对称性；转弯的真实响应与合理内倾；变高过渡与固定高度稳态分开 |
| 判定 | 协议版本、阈值、覆盖是否充分、质量是否合格、任务是否合格，以及各项未通过原因 |
| 证据 | 训练窗口、固定checkpoint独立验证、实机验证分别记录；含来源路径/SHA和实际条件 |

训练窗口含多个策略版本，只能记为该checkpoint附近的训练证据，不能标成该固定模型的独立成绩。课程晋级、训练best候选、固定模型验证通过与实机通过是不同状态，不相互代替。覆盖充分但任务失败记失败；缺覆盖或缺必要字段记UNKNOWN，不补造通过率。

新配方执行前须明确评分窗口、稳态/过渡边界、速度/yaw/高度容差、姿态/支撑/振荡/漂移门槛、扰动大小及恢复时限、最小覆盖量、基础保留门槛和退化判据。现有课程配置和候选阈值是各自版本的运行事实，不自动成为全矩阵独立验收标准。不可把宽松的站立通过率当成无明显溜车的充分证据。
